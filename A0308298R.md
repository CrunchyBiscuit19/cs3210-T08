## Exercise 10

The commands were run 5 times to test the configurations' performances. The raw data is described in the appendix.

Computation time dominates every run, so node speed decides the result. 

The `i7-7700` at `FrequencyBaseMHz=3600` has a higher clock frequency than `xs-4114` at `FrequencyBaseMHz=2200`. 
The `i7-7700` has 8 PUs and the `xs-4114` 20, but the latter's extra PUs go unused, since 5 processes already get one PU each on both nodes, so it does not help improve the performance.

The mixed run lands in between. The runs placed 3 ranks on the `xs-4114` and 2 on the `i7-7700`. Rows are split equally, so the `i7-7700` workers finish early and sit idle while the master waits for the slower `xs` workers. 

Both nodes still compute slightly faster than when run alone, likely because fewer processes per node means less contention for the shared L3 cache and memory bandwidth.

But since the master thread still has to wait on the slowest `xs-4114` nodes, it can only perform better than `xs-4114`-only run but not the `i7-7700`-only run. 

## Exercise 11

The slowdown comes from communication since it dominates the computation time. 

With 9 processes on 8 PUs, one rank is always descheduled. Blocking MPI calls force waiting ranks to spin instead of letting another rank do useful work. 

Any message involving the descheduled rank must then wait for the OS to replace a spinning rank with it, which balloons the communication time when working on a large matrix. 

With 5 processes, every rank has its own PU, so the same messages never wait.

## Exercise 12

Performance can be improved by making the waiting ranks yield their PUs instead of spinning. 

Replace each blocking `MPI_Recv` and `MPI_Send` with `MPI_Irecv` or `MPI_Isend`, then loop on `MPI_Test` until the request completes. 

An idle rank then gives up its PU so a descheduled rank able to do important work can run without being held up. 

All 9 processes still exchange the same messages and do the same computation. Only the way they wait changes, so the result stays correct.
